# Discord Collector migration

The combined [otelcol-extra distribution](../extra/README.md) replaces `discord-otelcol` and `otelcol-custom`.
It includes every custom component in this repository. Discord and SwitchBot can run in one service.

The `discord-otelcol` 0.2.0 package is a transitional dependency on `otelcol-extra`.
See the migration instructions before upgrading an existing installation.
